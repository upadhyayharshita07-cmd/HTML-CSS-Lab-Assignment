Assignment 2: Pushing and Cloning a Repository

B.Tech CSE - Second Year | HTML & CSS Introduction Lab (BCS352)

Experiment Aim

Send your commits to a second repository on your computer and make a copy of it with clone.

Task 1: Create Bare Repository and Configure Remote

A bare repository acts as a centralized server repository without a working tree. We created html-remote and configured it as origin:

# Inside html-lab:
git init --bare ../html-remote
git remote add origin ../html-remote
git remote -v
origin ../html-remote (fetch)
origin ../html-remote (push)

Task 2: Pushing Commits to Origin

Pushed the local branch to the newly configured remote repository:

git push origin master
To ../html-remote
* [new branch] master -> master

Task 3: Cloning Repository and Verifying Log

Cloned the remote repository into a sibling directory named html-copy and verified commit integrity:

cd ..
git clone html-remote html-copy
cd html-copy
git log --oneline
Cloning into 'html-copy'...
done.
81f3b2a (HEAD -> master, origin/master) Add home page and next meeting heading

Architecture Overview

Local: html-lab
(Working Tree + Git Repo)
─── git push ───>
Remote: html-remote
(Bare Git Repository)
─── git clone ───>
Clone: html-copy
(Identical Working Tree)
